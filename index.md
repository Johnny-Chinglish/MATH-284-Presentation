# Overview

This website presents our final paper presentation for **UCSD MATH 284: Lifetime Data Analysis**.

Our presentation is titled **Sparse Variable Selection in the Cox Model**. It focuses on Robert Tibshirani's 1997 paper, *The LASSO Method for Variable Selection in the Cox Model*, which adapts the lasso idea to Cox proportional hazards regression.

| Presenters | Presentation |
| --- | --- |
| Zhiyuan Zhang and Imani Elenor Beckett | [Sparse Variable Selection in the Cox Model](paper1.md) |

The presentation page includes slides, an algorithm handout, background papers, historical context, and a summary of the main ideas.
